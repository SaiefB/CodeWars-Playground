# Will He Survive?

A hero is on his way to the castle to complete his mission. However, he's been told that the castle is surrounded with a couple of powerful dragons!

## Problem

- Each dragon takes 2 bullets to be defeated
- The hero has a specific number of bullets
- The hero will face a specific number of dragons

## Challenge

Determine if the hero will survive the dragon encounter.

## Requirements

- Return `true` if the hero survives
- Return `false` otherwise

## Notes

The hero needs at least 2 bullets per dragon to defeat them all.
