# DNA to RNA Conversion

## Overview

Deoxyribonucleic acid (DNA) is the primary information storage molecule in biological systems. It is composed of four nucleic acid bases:

- Guanine ('G')
- Cytosine ('C')
- Adenine ('A')
- Thymine ('T')

Ribonucleic acid (RNA) is the primary messenger molecule in cells. RNA differs slightly from DNA in its chemical structure and contains no Thymine. In RNA, Thymine is replaced by Uracil ('U').

## Task

Create a function which translates a given DNA string into RNA.

## Example

```
"GCAT" => "GCAU"
```

## Input

- The input string can be of arbitrary length (may be empty)
- All input is guaranteed to be valid
- Each input string will only consist of 'G', 'C', 'A', and/or 'T'
